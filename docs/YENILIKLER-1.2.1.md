# Ray 1.2.1 · "Bu sürümdeki yenilikler" (App Store)

App Store "What's New" alanı emoji kabul etmiyor; metinlerde emoji yok. `tools/ios/metin.cjs` bu dosyayı okur (VERSION=1.2.1).

## tr

```
Hata düzeltmeleri:
• Bazı karolar ortasına dokununca dönmüyordu; düzeltildi.
• Kapışma ve lig bağlantısı kendini onarıyor; bağlantı yoksa ne olduğu açıkça yazıyor.
• Haftalık ligde arkadaşlar artık aynı gruba düşüyor.
```

## en

```

• Friends now land in the same weekly league group.
```
